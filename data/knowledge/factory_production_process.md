# 工廠生產流程假資料

## 生產流程總覽

食品機械設備的工廠流程通常從工程圖與 BOM 開始，經過材料準備、零件加工、焊接、拋光、電控配線、總組裝、測試與出貨。不同產品會有不同工序，但大多數客製設備都會經過跨工作站協作。

## 標準流程

### 1. 工程圖發行

工程圖未發行前，生產只能做初步產能預排，不可正式開工。若客戶尚未確認尺寸或現場資料，圖面狀態應為 pending_customer_confirm。

### 2. 材料準備

採購或倉庫需確認材料可用。食品接觸件常用 SUS304 或 SUS316L，若客戶指定 316L，需確認庫存與供應商交期。

### 3. 零件加工

CNC 主要處理閥座、軸類、鏈輪、調整座與精密配合件。加工前需確認工程圖版本，避免舊版圖加工造成報廢。

### 4. 板金與焊接

雷射切割完成後，焊接站進行槽體、機架、管路與護罩焊接。食品接觸區焊道需特別處理，避免清洗死角。

### 5. 拋光與表面處理

接觸食品的槽體內面、管路內側與充填零件需要拋光。若要求 Ra 0.8 以下，品保需安排表面粗糙度檢查。

### 6. 電控配線

電控工程負責 PLC、HMI、伺服、感測器、急停、安全門與配線。若客戶現場通訊協議不同，例如 Modbus、EtherNet/IP 或 Profinet，需在設計初期確認。

### 7. 總組裝

總組裝會整合機械零件、電控箱、管路、輸送線與安全護罩。若外購件未到，組裝可能只能做部分預組，不能進入完整測試。

### 8. FAT 測試

FAT 測試包含空機運轉、速度測試、漏水測試、電控功能、急停安全、清洗流程與客戶指定項目。測試異常需建立 issue，修正後重新驗證。

## 工單狀態

| 狀態 | 說明 |
| --- | --- |
| planned | 已排程但尚未開工 |
| waiting_material | 等待材料或外購件 |
| waiting_drawing | 等待工程圖 |
| in_progress | 生產中 |
| paused | 暫停，需原因 |
| qa_pending | 待品保檢查 |
| completed | 已完成 |
| blocked | 被前置條件阻塞 |

## 排程注意事項

- 同一零件不可同時排在兩個工作站。
- 有食品接觸要求的零件需安排品保檢查。
- 若同一訂單拆批出貨，需標示 batch_no。
- 若使用外包加工，需記錄外包廠商、交期與驗收標準。
- 系統需保護 in_progress 與 completed 工單，不可自動覆蓋。
